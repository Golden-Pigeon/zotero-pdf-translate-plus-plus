# Translate for Zotero++ 2.4.11

This release fixes how the reader popup sizes itself around rendered math, and
smoothes streaming translations. It widens the supported Zotero range beyond
9.0.x.

## Changes

- Wide formulas now render fully in the reader popup: the popup widens up to
  the reader width and shifts left when its position leaves too little room,
  instead of cutting formulas off behind a hidden horizontal scroll. Equation
  numbers such as (2) or (3) are visible without scrolling and no longer
  overlap the formula.
- The popup height follows the rendered content, removing the blank strip that
  could remain between the last translated line and the popup's bottom edge.
- Streaming services (GPT, Claude, Gemini, Youdao Zhiyun LLM) refresh the
  popup only when the result text actually changes, removing high-frequency
  resize flicker while the model is still emitting pre-content chunks.
- The reader no longer queues duplicate translation tasks when Zotero
  re-renders the text-selection popup over an unchanged selection.
- Widened the manifest compatibility range to Zotero 7.9.9 – 10.9.9, so the
  plugin installs across current and upcoming Zotero versions.

## Updating

Version 2.4.10 users can update normally; no restart is required beyond the
usual plugin update.

Users of the upstream plugin or version 2.4.8 must follow the
[one-time migration guide](https://github.com/Golden-Pigeon/zotero-pdf-translate-plus-plus/blob/main/docs/migration.md).
Keep the original plugin disabled; running both plugins together is unsupported.
