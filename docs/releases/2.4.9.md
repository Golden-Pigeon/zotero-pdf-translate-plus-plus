# Translate for Zotero++ 2.4.9

This release gives Translate for Zotero++ an independent plugin identity. It
supports Zotero 9.0.x.

## Changes

- Uses the plugin ID `zotero-pdf-translate-plus-plus@golden-pigeon`, with separate
  internal names, UI components, and preferences.
- Copies original plugin preferences once on startup, preserving existing new
  settings and leaving original settings unchanged.
- Prevents startup while the original plugin is enabled, and disables itself if
  the original plugin is enabled or installed later, to avoid duplicate
  translation actions and shortcut conflicts.
- Updates issue templates and release checks for independent maintenance.

## Installation

Users of the upstream plugin or Translate for Zotero++ 2.4.8 must install this
release manually because automatic updates cannot change a plugin's ID. Disable
the old plugin and restart Zotero before installing
`zotero-pdf-translate-plus-plus.xpi`. See the
[migration guide](https://github.com/Golden-Pigeon/zotero-pdf-translate-plus-plus/blob/main/docs/migration.md)
for settings migration and installation steps. Running both plugins together is
not supported.
