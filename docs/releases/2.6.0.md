# Translate for Zotero++ 2.6.0

This release adds independent GLM and DeepSeek services and a thinking effort
setting for each LLM translation provider.

## Changes

- Configure GLM and DeepSeek separately, including their API keys, endpoints,
  models, prompts, streaming, and custom request parameters.
- Choose thinking effort in the settings for ChatGPT, Azure GPT, Custom GPT
  1–3, GLM, DeepSeek, Gemini, and Claude. Each service saves its own choice.
  The default option preserves the model's existing behavior. Available
  levels depend on the provider and model.
- Map thinking settings to Chat Completions, Responses, Gemini thinking
  levels or budgets, and Claude adaptive or budget-based thinking. Custom
  GPT request parameters can override the generated thinking settings.
- Keep Claude thinking blocks and Gemini thought parts out of the translated
  text, including non-streaming responses with multiple text parts.
- Add English, Simplified Chinese, and Italian labels and compatibility hints.

## Updating

Users of version 2.4.9 and later can update normally. Open a translation
service's settings to select a thinking effort supported by its model.

Users of the upstream plugin or version 2.4.8 must follow the
[one-time migration guide](https://github.com/Golden-Pigeon/zotero-pdf-translate-plus-plus/blob/main/docs/migration.md).
Keep the original plugin disabled; running both plugins together is unsupported.
