# Translate for Zotero++ 2.4.8

First independently maintained release by Golden-Pigeon, based on [Translate for Zotero](https://github.com/windingwind/zotero-pdf-translate).

## Changes

- Includes upstream `main` through [`eae077e`](https://github.com/windingwind/zotero-pdf-translate/commit/eae077e), including the latest translation-service and cached-audio fixes.
- Merges all seven commits from `math-rendering-reader-popup` through [`44f081e`](https://github.com/Golden-Pigeon/zotero-pdf-translate/commit/44f081e).
- Adds math rendering to reader translation popups, with streaming updates, line-break normalization, and content-based popup sizing.
- Keeps the popup container aligned when manually resizing a text area.
- Uses this repository for downloads, automatic updates, and issue reports.

## Why an Independent Repository

I submitted [PR #1425](https://github.com/windingwind/zotero-pdf-translate/pull/1425) on May 15, 2026 (UTC), adding math rendering to the reader translation popup. The upstream maintainer [deferred it on June 1 because of a planned plugin refactor](https://github.com/windingwind/zotero-pdf-translate/pull/1425#issuecomment-4593330204) and [reiterated on September 1 that the feature would not be included in upcoming releases](https://github.com/windingwind/zotero-pdf-translate/pull/1425#issuecomment-5493466398). As of September 8, 2026, the PR remains unmerged after several months, while other contributors' PRs, including [#1434](https://github.com/windingwind/zotero-pdf-translate/pull/1434), [#1456](https://github.com/windingwind/zotero-pdf-translate/pull/1456), and [#1465](https://github.com/windingwind/zotero-pdf-translate/pull/1465), have been merged during that period. I therefore established this independent repository to continue developing, maintaining, and releasing these improvements.

## Installation

Download `zotero-pdf-translate-plus-plus.xpi` and install it through Zotero's plugin manager.

This version keeps the original plugin ID and preference keys. It replaces the upstream plugin and preserves existing settings; both versions cannot run side by side. Future automatic updates come from this repository.
