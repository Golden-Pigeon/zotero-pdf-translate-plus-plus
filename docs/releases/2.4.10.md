# Translate for Zotero++ 2.4.10

This release fixes remaining runtime isolation issues. It keeps the independent
plugin ID and supports Zotero 9.0.x.

## Changes

- Stops owned translation requests, queued work, retries, and fallback services
  when the plugin is disabled. Late results cannot update the interface or write
  translations to library items.
- Scopes formula styles and font names to this plugin. Styles load only when
  math rendering is needed, and owned styles are removed when the plugin stops.
- Registers versioned interface components and reads the current service manager,
  so hot updates do not reuse an earlier version's component implementation or
  service list.
- Cleans up owned windows and listeners and checks lifecycle state before adding
  an asynchronously translated selection to a note.

## Updating

Version 2.4.9 users can update normally. Users of the upstream plugin or version
2.4.8 must follow the [one-time migration guide](https://github.com/Golden-Pigeon/zotero-pdf-translate-plus-plus/blob/main/docs/migration.md).
Keep the original plugin disabled; running both plugins together is unsupported.
