# Translate for Zotero++ 2.5.0

This release adds a translation status bar to the reader popup, so LLM
translations show what they are doing instead of a static "Translating"
placeholder.

## Changes

- New status row pinned to the top-left of the reader translation popup.
  While a translation runs it shows the current stage — Prefill (request
  sent, first token pending) or Decode (tokens arriving) — with a live
  elapsed timer and, during decode, the streaming token count and speed
  in tok/s. The row sits above the translation text and stays in place
  while the popup auto-resizes under streaming text.
- On completion the row shows the service name, input/output tokens (↑/↓)
  when the service reports usage, and the total duration. Failures show a
  red ✗ with the elapsed time. Non-LLM services degrade gracefully to
  timings only.
- Token usage is read from each provider's own reporting: OpenAI-compatible
  endpoints (via `stream_options: include_usage`, overridable with custom
  request parameters), Ollama's prompt/eval counters, the OpenAI Responses
  API, Gemini's `usageMetadata`, and Claude's message usage events.
- New preference "Show Translation Status in Pop-up" (default on, under
  Settings → Translate → Basic) hides the row entirely.

## Updating

Version 2.4.x users can update normally; no restart is required beyond the
usual plugin update.

Users of the upstream plugin or version 2.4.8 must follow the
[one-time migration guide](https://github.com/Golden-Pigeon/zotero-pdf-translate-plus-plus/blob/main/docs/migration.md).
Keep the original plugin disabled; running both plugins together is unsupported.
