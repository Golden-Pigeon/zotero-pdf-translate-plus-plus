# Translate for Zotero++

Translate for Zotero++ is an independently maintained Zotero translation plugin
based on [Translate for Zotero](https://github.com/windingwind/zotero-pdf-translate).
It includes math rendering in the reader translation popup, with streaming updates
and improvements to line breaks and popup sizing.

## Why Independent Maintenance?

I submitted [PR #1425](https://github.com/windingwind/zotero-pdf-translate/pull/1425)
on May 15, 2026 (UTC), adding math rendering to the reader translation popup.
The upstream maintainer deferred the PR because of a planned plugin refactor and
[reiterated on September 1](https://github.com/windingwind/zotero-pdf-translate/pull/1425#issuecomment-5493466398)
that the feature would not be included in upcoming releases. As of September 8,
2026, it remained unmerged after several months, while other contributors' PRs,
including [#1456](https://github.com/windingwind/zotero-pdf-translate/pull/1456) and
[#1465](https://github.com/windingwind/zotero-pdf-translate/pull/1465), had been merged.
I therefore established this repository to continue developing, maintaining, and
releasing these improvements independently.
